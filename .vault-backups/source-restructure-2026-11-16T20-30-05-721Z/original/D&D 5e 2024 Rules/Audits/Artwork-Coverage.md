## Source and review notes

- Monster Manual: 258 entry links; Player’s Handbook: 387; Dungeon Master’s Guide: 184. The SRD scan yielded no usable decorative artwork.
- Shared scenes and overlapping item plates remain shared; class features use the corresponding class or subclass illustration, and ordinary enchanted armor variants use the illustrated base armor.
- Source artwork is retained, including its painted background and small labels embedded within illustrations. Text outside artwork is cropped away or made transparent where it overlaps the crop boundary. Subjects already cut off by a page edge remain as printed.
- A missing match below means no reviewed, reliable match was selected from these PDFs. It does not assert that the source contains no related image anywhere.
- Existing placeholders remain on unmatched entries, custom entries, indexes, and templates. No replacement artwork was invented.
- Source book, PDF page (1-based), crop coordinates, masks, file hash, and entry mappings are recorded in [[D&D 5e 2024 Rules/z. Load Bearing Folders/Attachments/Artwork/manifest.json]].
- Original notes and the previous CSS are backed up under .vault-backups/artwork-20261113.
- Verified every output’s dimensions, RGBA mode, file hash, bottom transparency, and absence of top/side fading. Verified all inserted links resolve and entry text differs only at its image embed.
- Visual checks used source-page contact sheets, finished-image contact sheets, and compositing on a light statblock color. The live Obsidian window was not inspected.
- Browse [[Artwork-Gallery]] for the extracted assets.
