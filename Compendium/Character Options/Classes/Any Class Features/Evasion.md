# Evasion

## Player's Handbook

> [!info]
> ### Evasion
>
> ![[Placeholder.png|320]]
>
> When you’re subjected to an effect that allows you to make a Dexterity saving throw to take only half damage, you instead take no damage if you succeed on the saving throw and only half damage if you fail. You don’t benefit from this feature if you have the [[Incapacitated|Incapacitated]] condition.
