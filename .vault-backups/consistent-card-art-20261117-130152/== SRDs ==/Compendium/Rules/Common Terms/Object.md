# Object

## SRD 5.2.1

> [!info]
> ### Object
>
> An object is a nonliving, distinct thing. Composite things, like buildings, comprise more than one object. See also  "[[== SRDs ==/Compendium/Rules/Common Terms/Breaking Objects|Breaking Objects]]."
