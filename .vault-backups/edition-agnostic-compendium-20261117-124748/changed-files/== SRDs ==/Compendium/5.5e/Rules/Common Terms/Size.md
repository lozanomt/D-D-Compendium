# Size

## SRD 5.2.1

> [!info]
> ### Size
>
> A creature or an object belongs to a size category: Tiny, Small, Medium, Large, Huge, or Gargantuan.
>
> A creature's size determines how much space the creature occupies in combat. An object's size affects its [[== SRDs ==/Compendium/5.5e/Rules/Common Terms/Hit Points|Hit Points]]. See also  "[[== SRDs ==/Compendium/5.5e/Rules/Common Terms/Breaking Objects|Breaking Objects]]" and "Playing the Game" ("Combat").
>
