# D20 Test

## Player's Handbook

> [!info]
> ### D20 Test
>
> ![[== SRDs ==/Sources/5.5e/Placeholder.png|320]]
>
> D20 Tests encompass the three main d20 rolls of the game: ability checks, attack rolls, and saving throws. If something in the game affects D20 Tests, it affects all three of these rolls. The DM determines whether a D20 Test is warranted in a given circumstance.
>
> **Source:** [[== SRDs ==/Sources/5.5e/Player's Handbook/D&D 5.5E - Player's Handbook.pdf|Player's Handbook]]

## SRD 5.2.1

> [!info]
> ### D20 Test
>
> D20 Tests encompass the three main d20 rolls of the game: ability checks, attack rolls, and saving throws. If something in the game affects D20 Tests, it affects all three of these rolls. The GM determines whether a [[== SRDs ==/Compendium/5.5e/Rules/Common Terms/D20 Test|D20 Test]] is warranted in a given circumstance. See also  "Playing the Game" ("D20 Tests").
>
