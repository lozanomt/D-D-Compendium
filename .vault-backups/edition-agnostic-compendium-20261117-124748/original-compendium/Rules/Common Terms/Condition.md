# Condition

## SRD 5.2.1

> [!info]
> ### Condition
>
> A condition is a temporary game state. The definition of a condition says how it affects its recipient, and various rules define how to end a condition.
>
> This glossary defines these conditions: [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Blinded|Blinded]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Charmed|Charmed]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Deafened|Deafened]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Exhaustion|Exhaustion]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Frightened|Frightened]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Grappled|Grappled]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Incapacitated|Incapacitated]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Invisible|Invisible]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Paralyzed|Paralyzed]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Petrified|Petrified]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Poisoned|Poisoned]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Prone|Prone]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Restrained|Restrained]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Stunned|Stunned]] [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Unconscious|Unconscious]] A condition doesn't stack with itself; a recipient either has a condition or doesn't. The [[== SRDs ==/Compendium/5.5e/Rules/Conditions/Exhaustion|Exhaustion]] condition is an exception to that rule.
