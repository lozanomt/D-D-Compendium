# Utilize

![[D&D 5e 2024 Rules/z. Load Bearing Folders/Attachments/Placeholder.png|320]]


You normally interact with an object while doing something else, such as when you draw a sword as part of the [[Rules/Actions/Attack]] action. When an object requires an action for its use, you take the Utilize action.
