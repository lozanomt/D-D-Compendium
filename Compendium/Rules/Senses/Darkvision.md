# Darkvision

## Player's Handbook

> [!info]
> ### Darkvision
>
> ![[Sources/5.5e/Placeholder.png|320]]
>
> If you have Darkvision, you can see in [[Compendium/Rules/Common Terms/Dim Light|Dim Light]] within a specified range as if it were [[Compendium/Rules/Common Terms/Bright Light|Bright Light]] and in [[Compendium/Rules/Common Terms/Darkness|Darkness]] within that range as if it were Dim Light. You discern colors in that Darkness only as shades of gray.
>
> **Source:** [[Sources/5.5e/Player's Handbook/D&D 5.5E - Player's Handbook.pdf|Player's Handbook]]
