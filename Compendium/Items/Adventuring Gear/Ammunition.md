# Ammunition

## SRD 5.2.1

> [!info]
> ### Ammunition
>
> [[Compendium/Rules/Properties/Ammunition|Ammunition]] is required by a weapon that has the
>
> [[Compendium/Rules/Properties/Ammunition|Ammunition]] property. A weapon's description specifies the type of ammunition used by the weapon.
>
> The [[Compendium/Rules/Properties/Ammunition|Ammunition]] table lists the different types and the amount you get when you buy them. The table also lists the item that is typically used to store each type; storage must be bought separately.
